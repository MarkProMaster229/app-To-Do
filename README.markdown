# 📝 Flask Task Manager

Это простое веб-приложение на базе Flask с функциями регистрации, авторизации и управления задачами. Данные хранятся в базе данных PostgreSQL.

---

## 🚀 Быстрый старт

### 📦 Установка зависимостей

```bash
pip install flask psycopg2-binary
```

### 🛠 Требования

- Python 3.8+
- PostgreSQL (рекомендуется установить через pgAdmin)
- Создана база данных `workdb`

Создайте базу данных в psql или PgAdmin:

```sql
CREATE DATABASE workdb;
```

### ⚙️ Настройки подключения

Убедитесь, что в файле `connector.py` указаны корректные параметры подключения:

```python
self.conn = psycopg2.connect(
    dbname="workdb",
    user="postgres",
    host="127.0.0.1",
    port="5432"
)
```

Если имя пользователя или пароль отличаются, измените их под свои настройки.

### 🧠 Автоматическое создание таблиц

При первом запуске приложения автоматически создаются:

- Таблица `users` — для хранения данных пользователей
- Таблица `tasks` — для хранения задач

**Ручное создание таблиц не требуется.**

### ▶️ Запуск приложения

```bash
python inside.py
```

Приложение будет доступно по адресу: [http://127.0.0.1:5000/](http://127.0.0.1:5000/)

---

## 💡 Возможности

- Регистрация и авторизация пользователей
- Добавление задач с дедлайнами и описанием
- Автоматический подсчёт дней до дедлайна
- Сортировка, удаление, редактирование и отметка задач как выполненных
- Тёмный режим (переключается через cookie)
